Generative Art: Composition Creator

Combining programming logic with creative experimentation to produce unique, algorithmically generated visual compositions.

Composition Creator is an interactive generative art project developed using Processing (Java). It explores the relationship between randomness, color, shape, and visual composition to create unique abstract artwork.

Using algorithmic techniques, the program generates layered compositions of geometric shapes, including circles, ellipses, and rounded rectangles. Each shape is assigned randomized colors, sizes, transparency levels, and positions, resulting in an evolving visual composition. A random selection from 4,495 emojis from openmoji.org are part of the layered composition with random positioning and transparency.

The project also incorporates external image assets, allowing imported images to become part of the generated artwork through randomized placement and color tinting. Users can pause the animation and capture individual compositions, which are automatically saved as timestamped PNG files.

Technologies and Tools

  • Java programming concepts
  • OpenMoji (CC BY-SA 4.0 licensed image assets)
  • Processing graphics and image libraries

Code Trivia

Designed and developed an interactive trivia application focused on computer science history and technology. The application features a series of expandable questions that reveal answers when clicked, creating a simple and engaging user experience.

Using HTML, CSS, JavaScript, and jQuery, I implemented interactive accordion-style functionality with smooth slide animations and dynamic styling to provide visual feedback when users interact with questions.

The project also features custom CSS styling, a responsive-centered layout, a soft gradient background, hover effects, and Google Fonts typography to create a clean and approachable interface.
